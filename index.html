Shader Workshop is a simple offline playground for Shadertoy-style shaders — written in C/C++.

Standalone Linux & Windows app. Multipass, float buffers, video, webcam, audio, freefly camera, and full-frame SIMD control. Runs entirely on the CPU via PortableGL.

Get it on itch.io Feature comparison
NOTE for ADVENTURERS: This is not an in-browser GLSL editor. You write real C/C++ (GLM, rsw_math, or PortableGL math), compile to a shared library, and step through with a normal debugger. Are you ready to enjoy coding?

#features

A Shadertoy-like runtime without the browser — and with the power of a real C toolchain.

  • C/C++ shaders — GLM, rsw_math, PortableGL builtins, or your own code
  • Open sources directly — auto-compile to .so/.dll, file-watch reload
  • OpenMP — live thread-count control for performance tuning
  • Frame shaders — write the whole framebuffer (SIMD-friendly mainFrame)
  • No GPU required — software rendering via PortableGL
  • Multipass — buffers, float storage (RGBA32F), per-pass resolution, recursion
  • Media — 2D, cubemaps, volumes, video files, webcam, screen capture
  • Audio — mainSound, FFT/wave textures, mic, post-mix analysis
  • Freefly camera — built-in uniforms for 3D exploration
  • Export — screenshots, MP4 video, audio-only export
  • Time & resolution control — pause, scrub, FPS lock, canvas size
  • Custom UI params — do_user_gui for live knobs

#why does it exist?

There are plenty of shader-art sites: Shadertoy, twigl, GLSLsandbox, oneshader, sledit, FragCoord, and more. Shader Workshop exists for people who want a Shadertoy-like workflow offline — no browser, no mandatory internet — and who prefer the full power of C/C++ over GLSL ergonomics alone.

Step through a shader line by line. Insert print statements. Keep real state. Mix rasterized geometry with image-style passes. Use the tools you already know for debugging and profiling. Chase FPS on the CPU if that is your idea of fun.

Supporting the project also supports ongoing work on PortableGL and Nuklear — bugs fixed and features added because this app needed them.
